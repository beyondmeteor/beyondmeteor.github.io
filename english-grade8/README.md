# 八年级英语 · 15 分钟课后练习 MVP

针对人教版八年级上册假期主题的**原创演示**，不是官方教材配套题库。此版本重点验证学习路径与页面，不声称覆盖新版全部单元。

## 已实现

- **单词精学**：一屏 6 词；语音讲解、听辨、跟读、例句朗读、拼写；语音/答题正确后自动进入下一环节。
- **15 分钟计时**：浏览器内倒计时、暂停/继续；按计划推荐将时间分为精学 8 分钟、练习 6 分钟、批改复盘 1 分钟（实际时长因孩子答题与模型响应变化）。
- **综合练习**：单词听写、动词变形、完形填空，共 10 题、100 分；浏览器打印。
- **拍照批改**：手机拍摄答卷，后端调用支持视觉输入的 OpenAI 模型，返回逐题分数、识别内容、参考答案、解析及薄弱项。不能辨认的题标记人工复核。
- **隐私**：图片不写入磁盘；通过后端转发到模型服务，API Key 不放在前端。上线前仍应配置 HTTPS、用户授权、速率限制和数据保留策略。

## 本地运行

```bash
cd english-grade8
node --version  # Node.js 20+
npm start
# 浏览器打开 http://localhost:3000
```

启用拍照批改：

```bash
export OPENAI_API_KEY='your-api-key'
export OPENAI_MODEL='gpt-4.1-mini'
npm start
```

注意：模型名需对应账户实际可用、支持图片输入和 JSON 输出的模型，产生 API 费用。不设 Key 时领学、打印仍可使用。

## 实施边界

1. Web Speech API 的 SpeechRecognition 浏览器兼容性不一致，手机端可能无法工作；不支持时**不虚假判定口语通过**。当前识别是词句匹配，并非语音声学评分。生产版需要专用 ASR/发音评测服务与容错策略。
2. 现在采用原生浏览器合成语音；首次页面交互后开始播放。长文本语音事件行为因浏览器而异。
3. 手写 OCR 和语义判分由视觉模型承担，可能出错；空白、遮挡、不确定答案需要人工复核。当前批改只对应固定的 10 道样题。
4. 词库和试卷为原创示例，正式对齐人教版 2024 新教材须逐单元核对经授权的目录/词汇/语法要求。
5. 学习进度保存在 localStorage；服务重启不影响浏览器进度，但不同设备不同步。倒计时不跨页面刷新保存。
6. 本仓库是个人公开博客的独立子目录演示；不要在博客生产站点直接暴露无鉴权限的模型调用接口。
